# Princípio 2 — Escuta Ativa

> Escutar para dar a resposta **definitiva**, não a imediata. Demonstrar interesse,
> disponibilidade, presença e acolhimento.

## Por que isso importa na Millenium

Já tivemos um volume relevante de casos em que **nos comprometemos a fazer X quando o cliente
precisava de Y** — e a causa foi a falta de perguntas certas e profundas no atendimento/venda.
Nossa operação de soluções para empresas só é eficiente se compreendemos o **real problema**;
caso contrário, geramos ainda mais conflito e dissabor.

## Objetivo do princípio

Desenvolver a capacidade de ouvir de verdade — não para produzir uma resposta rápida, mas para
entregar a solução que **realmente resolve**.

## Antes de responder, reflita

- Quais são **todos** os questionamentos que preciso fazer para ajudar este cliente?
- Já tenho **todas as informações** para fazer meu trabalho com maestria?
- Tenho certeza de que a medida que vou tomar **resolve mesmo** o problema?
- Qual é o **impacto** desse processo que vou executar?

## O ciclo com o cliente

1. **Ouvir/ler tudo** com atenção; verificar cada aspecto **antes** de formar opinião ou resposta.
2. **Perguntar** o que ficou faltando ou não esclarecido — todas as perguntas necessárias, deixando o cliente se expressar do jeito dele.
3. **Recapitular e validar**: confirmar se o que você entendeu é o que de fato aconteceu, ou se houve ruído.
   - *"Só para confirmar se entendi corretamente…"*
   - *"Então, o que está ocorrendo é…"*
4. **Explicar** o que será feito e **por quê**.
5. **Validar a solução**: confirmar se o que foi apresentado atende à expectativa e resolve o desafio.

## Como o agente aplica

- No copiloto de conversa, gera **perguntas de descoberta** (ver `perguntas-descoberta.md`) em vez de pular para a solução.
- Sempre oferece uma frase de **recapitulação** para o atendente validar com o cliente.
- Antes de sugerir uma tratativa, checa se há **informação faltando** e sinaliza o que ainda precisa ser perguntado.
- Nunca propõe "fazer X" sem que o problema Y esteja claro — se estiver ambíguo, pede confirmação primeiro.
